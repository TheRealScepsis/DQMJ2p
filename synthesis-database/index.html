About this database

This is an unofficial fan reference for Dragon Quest Monsters: Joker 2 Professional (DS, Japan-only — commonly played via the English fan translation). It combines:

  • 333 synthesis recipes (rank/family formula syntheses)
  • 150 skill upgrade combinations
  • 336 monster icons

Monster synthesis recipes come from a Professional-specific synthesis export. Skill upgrade combinations come from Dragon's Den, the long-standing Dragon Quest Monsters fansite (Skill Upgrade Requirements page for DQMJ2).

Synthesis Tree renders a monster's full ancestry as a diagram or an outline; Builder shows the same ancestry as a compact, collapsed-by-default parts list you expand only where you want more detail.

Data is static and searched entirely client-side — no server, no tracking.
